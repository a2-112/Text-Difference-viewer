# LCS Text Difference Viewer

A JavaScript text comparison tool that uses the **Longest Common Subsequence (LCS)** algorithm to compare two texts and highlight matching and different characters.

## Features

* Compare two texts using LCS
* Highlight matching and different characters
* Show matched text and similarity percentage
* Unicode-aware text handling
* Save comparison history with `localStorage`
* Delete individual history records
* Clear comparison history
* Responsive interface

## How It Works

1. Enter two texts.
2. The LCS algorithm finds their longest common subsequence.
3. Matching and different characters are highlighted.
4. A similarity percentage is calculated.
5. Comparisons can be saved and viewed in history.
